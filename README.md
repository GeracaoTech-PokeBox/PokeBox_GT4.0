# PokeBox

Aplicação onde treinadores possam gerenciar suas coleções de pokémons e trocar pokemons com outros treinadores.

Feito durante o curso FullCycle - Engenharia de Software do projeto Geração Tech 4.0

## Stack

- Node.js
- JavaScript
- Cypress
- Mochawesome
- MySQL
- React
- Docker Compose

## Testes automatizados

Os testes E2E usam Cypress com Page Objects e relatórios Mochawesome. A configuração e as dependências da automação ficam na raiz do projeto.
